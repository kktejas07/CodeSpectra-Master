# Learn Hub Guide

The Learn hub (`/learn`) publishes short technical articles: concepts, algorithms and interview topics, with code in several languages and links to practice problems.

## Reading

Browse by category, level or series, search by title, and follow the RSS feed (`/learn/rss.xml`). Each post links to related posts and to practice problems on the same topic.

## How posts are written (platform admins)

**Admin → Learn** manages topics and posts.
- **Topics** are the subjects the generator writes about. Add, edit, enable or disable them.
- The generator researches allowed sources, writes a **draft** and gives it a quality score with any flags (for example a reference page that looked like an instruction to the AI is dropped and flagged).
- Every draft needs an admin action: **approve**, **publish** now, **schedule** for later, or **reject** with a reason. Published posts can be unpublished (archived) and republished.
- Auto-approve is off by default. When turned on, only drafts above the minimum score and with no flags publish on their own.

The AI copilot can list drafts, write new drafts for chosen topics, and draft approve / publish / reject actions for you to confirm.
