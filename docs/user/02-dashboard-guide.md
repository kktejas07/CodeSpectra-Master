# Dashboard Guide

## Overview

The CodeSpectra dashboard is your central hub. After logging in, you land on the **Overview** page (`/dashboard`) showing your stats, activity, and quick actions.

## Navigation

### Sidebar

The left sidebar is your primary navigation. It contains:

- **Logo / Home** — click to return to your default dashboard
- **Command search** — a search bar to find pages, problems, and features quickly
- **Main navigation** — links to Problems, Scanner, Agent, Learning, Skill Analytics, Leaderboard, Achievements, Certifications, Pricing, and more
- **Collapse button** — toggle between full-width and compact (icon-only) sidebar
- **Bottom bar** — your avatar (opens profile menu), theme switcher, notifications bell, and sign-out

The sidebar adapts to your role. Superadmins see Admin sections. Tenant admins see Organization management.

### Breadcrumbs

A breadcrumb trail is displayed at the top of every dashboard page. It shows your current location and lets you navigate up one or more levels.

### Mobile

On smaller screens the sidebar becomes a slide-out overlay. Tap the hamburger menu (top-right) to open it.

## Overview Page

The Overview page (`/dashboard`) includes:

### Stats Cards
- **Code Scans** — total scans run
- **Challenges** — coding challenges completed
- **Fixes Applied** — AI-suggested fixes you've applied
- **Daily Challenge** — today's challenge widget (with streak info)

### Contribution Graph
A GitHub-style heatmap showing your daily activity (scans, reviews, fixes, challenges) over the past 14 weeks.

### Quick Actions
Grid of shortcuts to: Run Scan, Challenges, Problems, Arena, Tracks, Achievements.

### Recent Activity
A timeline of your latest actions across the platform.

### Your Stats
Breakdown of scans, challenges completed, daily challenges, reviews, fixes applied, and current streak.

### Learning Progress
A card linking to Learning Tracks to continue your learning journey.

## Profile

Access your profile from the avatar dropdown in the sidebar.

The profile page (`/dashboard/profile`) shows:
- **Avatar** — generated from your name
- **Display name and email**
- **Edit profile button**
- **Stats** — code scans, code reviews, fixes applied, integrations
- **Digital ID Card** — a shareable credential card
- **Contribution Graph** — activity heatmap
- **Recent Activity** — latest actions
- **Contribution Breakdown** — visual stats cards
- **Two-Factor Auth** — set up or disable 2FA using any authenticator app (TOTP)

## Settings

Access settings (`/dashboard/settings`) from the avatar dropdown.

Settings are organized into sections:

### Appearance
- **Theme** — choose Light, Dark, or System (follows sidebar theme toggle)
- **Language** — select from English, Español, Français, Deutsch, 中文

### Notifications
- **Email** — toggle product and account email updates
- **Push** — toggle in-browser alerts

### Security
- **Two-factor authentication** — toggle (full setup is on the Profile page)
- **Change password** — update your account password

### Danger Zone
- **Export my data** — download your data
- **Delete account** — permanently remove your account (irreversible)

## Search

The **Command Menu** (accessible from the sidebar search bar) lets you search across the platform. Type to find pages, problems, and features quickly.

## Keyboard Shortcuts

- `Ctrl+K` / `Cmd+K` — open command search
- `Esc` — close dialogs and menus
