# Getting Started with CodeSpectra

## 5-Minute Quickstart

Get up and running with CodeSpectra in under five minutes. This guide walks you through creating an account, running your first code scan, attempting a coding challenge, and using the AI chat.

---

### Step 1: Create Your Account

1. Navigate to [app.codespectra.ai/signup](https://app.codespectra.ai/signup)
2. Choose one of three signup methods:
   - **Email & Password** — enter your email address and create a secure password
   - **Google** — click the Google OAuth button to authenticate with your Google account
   - **GitHub** — click the GitHub OAuth button to authenticate with your GitHub account
3. Complete the signup form and click **Create Account**

> **What you'll see**: A confirmation screen with your name and email. You'll be redirected to your personalized dashboard.

---

### Step 2: Your First Code Scan

1. From the dashboard, click **Code Scanner** in the sidebar
2. Choose your input method:
   - **Paste Code** — paste a snippet directly into the editor
   - **Upload File** — upload a source file from your computer
   - **GitHub Repository** — connect a GitHub repo (requires GitHub login)
3. Click **Scan Now**
4. Wait 3–5 seconds while CodeSpectra analyzes your code

> **What you'll see**: A results dashboard showing:
> - **Quality Rating** — A through E score (A = excellent, E = poor)
> - **Issues Found** — categorized by severity (Critical, Major, Minor)
> - **Security Hotspots** — potential vulnerabilities
> - **Code Smells** — maintainability concerns
> - **AI Suggestions** — click any issue to see an AI-generated fix

---

### Step 3: Your First Coding Challenge

1. Click **Problems** in the sidebar
2. Browse the problem catalog or use the filter bar to narrow by difficulty (Easy, Medium, Hard) or topic (Arrays, Strings, Dynamic Programming, etc.)
3. Click a problem to open it — you'll see:
   - **Problem Statement** — description, input/output format, and examples
   - **Constraints** — time and memory limits
   - **Code Editor** — pre-loaded with starter code in your preferred language
4. Write your solution in the editor
5. Click **Run** to test against sample cases
6. Click **Submit** to run against all test cases

> **Pro tip**: Use the language selector at the top of the editor to switch between 40+ supported languages. CodeSpectra remembers your preference.

---

### Step 4: Ask the AI

1. Open any problem and click the **Ask AI** button (or use the AI Chat icon in the bottom-right corner)
2. Type a question like:
   - "How do I approach this problem?"
   - "What's the time complexity of my solution?"
   - "Can you give me a hint?"
3. CodeSpectra responds in real-time with progressive hints:
   - **Level 1**: Conceptual nudge ("Think about using a hash map")
   - **Level 2**: Algorithm outline ("Here's a step-by-step approach...")
   - **Level 3**: Pseudo-code ("Try this logic...")
   - **Level 4**: Full solution (only if you ask)

> **What you'll see**: A streaming response from the AI, powered by Claude Sonnet 4.5. The AI has context of the problem statement and your current code.
