## Competitive Positioning

### CodeSpectra Differentiators

1. **AI-Native Architecture** — Unlike HackerRank/LeetCode which bolt on simple hints, CodeSpectra has deep AI integration: multi-step agents, rubric-based grading, PR review bots, identity verification, skill analytics, and a question generator.

2. **Unified Code Quality + Assessment** — Combines static analysis (SonarQube-like), security scanning (Snyk-like), coding assessments (HackerRank-like), and AI review in a single platform — competitors typically specialize in one area.

3. **Open Source + Self-Hosted** — Full Docker deployment with no vendor lock-in. Piston code execution runs locally. Self-contained AI routing via FastAPI.

4. **Multi-Provider AI** — Not tied to one LLM. Uses Anthropic Claude, Google Gemini, and OpenAI GPT-4o-mini with a model registry pattern in `ai_router.py`.
